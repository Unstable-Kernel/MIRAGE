# MIRAGE Support

Use the appropriate channel so maintainers can respond efficiently.

| Need | Channel |
|---|---|
| Bug in an implemented capability | GitHub issue with reproduction, revision, environment, and logs with secrets removed |
| Feature proposal | GitHub issue describing the engineering problem and acceptance criteria |
| EIR or URCP change | Specification-change issue followed by an RFC |
| Security vulnerability | Private email to `kshitiz23kumar@gmail.com`; do not use a public issue |
| Usage question | README, guides, or GitHub Discussions when enabled |

Please do not include API keys, private research artifacts, proprietary CAD, or unredacted provider responses in issues.
